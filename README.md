# Unstick (prototype)

A tiny, low-pressure first move when you feel creatively stuck. This is a design prototype, not a finished product.

**Open it:** https://YOUR-USERNAME.github.io/YOUR-REPO/  (replace with your own)

**Presenting?** Add `?demo=1` to the address to show a small "tools" button (speed up timers, fill sample data, simulate three days later, switch prompt wording).

**What is real and what is not**
- Everything is saved only in your own browser. There is no server.
- Sign up, the anonymous wall and Monthly Mischief are concepts: nothing is sent, shared or charged.
- A web page cannot lock a phone. The phone lock only works inside the app screen.

**On a phone:** open the link in Safari or Chrome, then Share > Add to Home Screen.
